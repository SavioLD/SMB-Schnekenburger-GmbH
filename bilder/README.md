# Bildmaterial / bilder-Ordner

Hier kommt das Bildmaterial der SMB Schnekenburger GmbH hinein. Sobald die
Dateien im Ordner liegen, werden sie **automatisch** von der Karriereseite
eingebunden – der Code muss dafür nicht angepasst werden.

## Logo (ersetzt automatisch den Text-Schriftzug „SMB")

| Datei | Verwendung |
|-------|------------|
| `smb-logo.svg` oder `smb-logo.png` | Logo in der Kopfzeile (dunkel, auf hellem Grund) |
| `smb-logo-weiss.svg` oder `smb-logo-weiss.png` | Logo im Hero-Bereich und im Footer (hell, auf dunklem Grund) |

Fehlt eine helle Variante, wird automatisch das normale Logo bzw. der
Text-Schriftzug verwendet.

## Hero-Hintergrundbild (optional)

| Datei | Verwendung |
|-------|------------|
| `hero.jpg` (alternativ `hero.webp` / `hero.png`) | großflächiges Hintergrundbild im Kopfbereich (z. B. Produktion, Team, Maschinen). Empfohlen: mind. 1920 px breit, quer. |

Liegt kein `hero.*`-Bild vor, bleibt der Navy-Farbverlauf des CI stehen.

## Empfehlung
- Logo bevorzugt als **SVG** (scharf auf allen Displays).
- Fotos im Querformat, Motiv nicht zu mittig (linke Seite wird vom Text überlagert).
